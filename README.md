# Mini PKI · RSA / SM4

一个用于密码工程课程的本地 PKI 实验系统，使用 Node.js、Express 和原生 HTML/CSS/JavaScript，演示证书申请、签发、吊销、RSA 文件签名验签以及 SM4 加解密。

## 功能

- 首次启动自动生成 RSA 2048 位根 CA、证书和本地数据。
- 申请并审核签发 X.509 证书，下载证书、公钥和私钥。
- 使用 RSA-SHA256 签名、验签，并检查证书签发链和吊销状态。
- 查看 JSON 格式吊销列表和操作记录。
- 使用 SM4-ECB 加解密测试文件，并对比 SHA-256 摘要。

## 快速开始

需要 Node.js 22 或更新版本与 npm。克隆项目后运行：

```sh
git clone https://github.com/0000054/pki-rsa-sm4.git
cd pki-rsa-sm4
npm ci
npm start
```

浏览器访问 **http://127.0.0.1:3000**。服务仅监听本机回环地址。

Windows PowerShell 若限制 npm.ps1，可使用 `npm.cmd ci` 和 `npm.cmd start`。安装依赖后，也可双击 `start.bat` 启动并打开浏览器。

## 演示流程

1. 提交一个测试证书申请，例如 alice.pki.test。
2. 审核申请并签发证书，查看证书详情和下载功能。
3. 选择证书、上传测试文件，生成签名，再使用原文件验签。
4. 修改文件后重新验签，观察失败结果。
5. 吊销证书后重新验签，观察证书状态检查失败。
6. 上传测试文件进行 SM4 加密，再解密并核对摘要。
7. 查看吊销列表和操作日志。

## 测试

```sh
npm test
```

集成测试从空的临时数据目录启动独立服务，覆盖 CA 初始化、申请签发、签名验签、篡改检测、SM4 往返和吊销检查。测试退出后清理临时密钥，不改动运行数据。GitHub Actions 自动运行相同测试。

## 目录

```text
src/server.js       Express API、证书和密码运算
public/             前端页面、样式和交互
test/               集成测试
start.bat           Windows 启动脚本
data/               首次运行时生成，不纳入 Git
```

可通过环境变量 PORT 修改端口，通过 PKI_DATA_DIR 指定本地数据目录；默认端口为 3000。

## 实验边界与数据

本系统仅用于本机课程实验，**不要部署为公网服务或用于真实证书、真实用户数据和生产加密**：

- 没有用户登录和管理员权限隔离，演示页面允许下载私钥及查看 SM4 密钥。
- 私钥与证书数据以明文文件形式保存在本机 data/ 中。
- SM4 使用 ECB 模式，未提供认证加密，不是生产环境推荐的文件加密方案。
- 吊销列表为 JSON 演示数据，并非标准签名 X.509 CRL；未实现 OCSP、HSM 或完整证书策略及有效期校验。

仓库不包含原作业压缩包中的 CA 私钥、证书库和历史记录；每位使用者会生成独立实验数据。请勿将生成的 data/、PEM 或密钥文件提交至 Git。重置实验前请先备份自己的数据，再停止服务并移除本地 data/。
